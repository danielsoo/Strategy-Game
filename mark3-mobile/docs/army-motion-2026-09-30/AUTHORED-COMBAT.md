# 대련 동작 5: 골격 중심과 실제 파일 축척부터 수정

이전 버전의 수치 검사는 팔의 모양이 자연스럽다는 증거가 아니었다. 사용자가 제공한 화면에는 손목·팔꿈치 꺾임이 남아 있었다.

## 확인한 원인

- 원본 기사에는 골격이나 애니메이션이 없다. 검 끝을 표적으로 끌어당기는 임시 IK가 팔 전체의 자세를 결정했다.
- 원본 장갑 시작점은 기존 손목 중심보다 몸 가까이에 있었다. 새 관절 중심은 키 1.75 기준 어깨 `(±0.24,1.35,-0.075)`, 팔꿈치 `(±0.425,1.21,-0.075)`, 손목 `(±0.565,1.12,0.035)`이다.
- 방패 분류는 원본 좌표의 고정 수치 20/40을 사용했다. 실제 glTF 노드는 0.0299875 배 축척을 가진다. 브라우저에서 방패가 신체로 분류되어 팔과 함께 휘었다. Node 테스트 로더가 노드 축척을 누락해 이 문제를 놓쳤다.

## 변경

- 방패 분류를 모델 높이에 대한 비율로 수정하고, 테스트 로더에도 glTF 노드 축척을 적용했다.
- 대련은 Quaternius CC0 클립을 재생한다. 원본의 어깨·팔꿈치·몸통 회전을 유지하면서 기사 체형으로 옮긴다. 검 끝을 맞추는 IK는 대련 경로에서 사용하지 않는다.
- 원본의 열린 손 대신 원본 골격으로 쥔 손을 추출했다. 검 손잡이와 닫힌 주먹을 같은 좌표계에 고정했다. 과도한 손목 플릭은 아래팔에서 12도까지 제한한다.
- 원본 검의 큰 곡선 가드는 직선 십자 가드를 갖춘 한손검으로 교체했다. 방패는 별도의 강체 메시로 분리했다.
- 접촉 전에 방패를 세우고, 막힌 베기는 접촉 클립에서 반동·회수로 이어진다. 두 번째 베기는 별도의 클립을 사용한다. 세 번째 교환은 방패가 낮아진 빈틈에 피격 반응을 연결한다.
- 검토 화면과 실제 맵의 대련은 같은 컴포넌트를 사용한다. 8.4초 대련 길이에 맞춰 기존 전투 종료 대기 상수도 함께 늘어난다.

## 재생성·검증

원본 ZIP과 glTF는 `.realm-source/animation/`에 보관한다. `node tools/prepare-knight-motion.mjs`로 필요한 5개 클립의 60 Hz 관절 데이터와 손 메시를 재생성한다. 출처와 라이선스는 `public/realm/knight/CREDITS.md`에 기록했다.

`tools/check-authored-combat.ts`는 양쪽 선공/승패 조합에서 관절 유한성, 12도 손목 제한, 주먹과 손잡이 고정, 발 지지, 전환 연속성, 실제 방패 메시와 접촉 위치를 검사한다. 두 차례 방패 접촉 오차는 약 1.6 mm / 0.5 mm다. 이 검사는 자연스러움에 대한 사용자 평가를 대신하지 않는다.

실제 브라우저에서 사선베기·반격·준비·회수와 손목 확대를 검토한다. 여전히 수작업으로 체형에 맞춘 리타기팅이며, For Honor의 전용 모션캡처·캐릭터 리그와 동등한 결과라고 주장하지 않는다.
