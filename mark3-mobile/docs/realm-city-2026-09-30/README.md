# 중세 시가지 개편 — 2026-09-30

반복되는 단순 건물과 비어 있는 성 주변이 장난감처럼 보인다는 피드백에 따라, 건축 형상과 시가지 구성을 교체했다.

- Millennium A.D.의 저작된 건축 16종을 glTF로 변환했다. 목재 골조, 문, 창, 지붕, 석조 예배당, 시장 천막과 좌판을 원본 형상·UV로 표시한다. 실행 중 외부 자산 서버에 접근하지 않는다.
- 왕실 영주관, 석조 수도원, 목조 변경 요새를 각각 중심 건물로 사용한다. 성마다 내부 주택 10채와 외곽 주택 28채, 시장, 작업장, 창고 및 골목을 배치한다. 좌표 기반 결정론적 배치다.
- 성벽을 낮추고 병사 크기를 조정했다. 주변 지형을 넓게 평탄화해 외곽 주택이 산에 파묻히지 않게 했다. 급경사에는 농가·경작지를 두지 않는다.
- 밭의 고랑과 색상, 지면, 수목 밀도를 조정했다. 생성 시안 대신 현재 브라우저의 실제 3D 렌더를 메인 배경으로 사용한다.
- 건축은 자산별 인스턴싱으로 공유한다. 새 아트 파일은 약 36 MB이며 이전 성곽 모델은 런타임에서 로드하지 않는다. 실제 휴대폰 GPU의 성능 수치는 측정하지 않았다.

## 검증

`tsc --noEmit`, `tools/check-realm-scene.ts`(11×11, 21×21), `sim/medievalScene.test.ts`, `tools/check-realm-assets.cjs`, Expo 웹 export 통과. 렌더링이 상태를 변경하지 않는지, 미탐험 지역 정보가 노출되지 않는지, 지형의 모든 칸을 레이캐스트로 선택할 수 있는지 확인했다.

브라우저에서 실제 저장 게임과 `?art=1`의 3종 도시를 확인했다. 캡처는 후처리 없는 실제 렌더링이다. 390×844 휴대폰 크기의 레이아웃도 확인했다. 이것은 문명 수준의 전체 아트 제작이 완료됐다는 의미가 아니며, 병사 애니메이션이나 신규 게임 규칙은 이번 변경에 포함되지 않는다.
