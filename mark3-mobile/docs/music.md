### 표본의 출처와 사용 허락

- **tonejs-instruments** (npm `tonejs-instrument-*-mp3`, Makefully-Studios) — MIT.
- **FluidR3 GM** (Frank Wen) — MIT. npm `soundfont-for-samplers` 가 mp3 로 바꿔 둔 것.
- 굽는 데만 쓴 **lamejs** (LGPL) 는 게임에 들어가지 않는다.

출시 전에 표본 원본의 허락 조건을 한 번 더 확인할 것 — 특히 tonejs-instruments 의 표본은
여러 곳에서 모은 것이라 npm 의 MIT 표기와 원 녹음의 조건이 다를 수 있다.

### 다시 굽는 법

    bash tools/music/fetch-samples.sh /tmp/mark3-music
    (cd /tmp/mark3-music && python3 -m http.server 8777 &)
    MUSIC=/tmp/mark3-music NODE_PATH=$(npm root -g) node tools/music/render.js

클라우드 Chromium 에서 수 분 걸린다(사건 1287, 표본 119). 표본을 내주는 서버(8777)가
떠 있는지 먼저 볼 것 — 안 떠 있으면 굽기가 죽고, 옛 PCM 으로 mp3 를 다시 만든다.

## 고친 것 (같은 날, 사람이 들어보고)

"바이올린이 뚝뚝 끊기고, 45초쯤부터 음정이 조금 나가고, 1분 뒤부터 끊기는 소리가 심하다."

- 끊김: 합주를 3.1초 FluidR3 표본으로 만들고 2초마다 다시 겹쳤다 → 11~16초 바이올린 표본을
  셋씩(-7/0/+6센트) 겹치고, 같은 음은 마디를 넘어 이어 붙이고, 바뀌는 음은 0.4초 겹친다.
  선율은 레가토. 고친 뒤 '10ms 크기가 앞 100ms 평균의 40% 아래로 떨어지는 순간' 0번.
- 45초 음정: 응답 선율 넷째 마디 C♯ 이 C 장화음과 부딪혔다 → C·G.
- 1분 뒤: 작은북 연타(초당 10번)·첼로 스타카토·3초 표본 트레몰로 → 빼고 현의 부풂·팀파니
  구름·심벌즈 차오름으로.

## 버린 것

1. **낮은 지속음 + 도리안 몇 음** (처음) — 사인·세모파. "노래가 안 어울린다, 오케스트라로".
2. **브라우저에서 빚은 관현악** (`orchestra.ts`) — 톱니파를 겹친 현악, 비브라토 호른, 합성
   팀파니, 2.8초 잔향. "여전히 기계음 같다, 실제 악기 소리로".
3. 표본을 쓰되 **게임 안에서 실시간으로 연주**하는 길 — 표본이 20MB 넘게 필요해 폰에서
   받기 무겁다. 미리 구운 2MB 한 곡으로 했다.

## 한계 — 사람이 들어보고 판단할 것

표본은 '한 사람이 한 음을 낸' 녹음이다. 실제 악단은 음과 음 사이(활의 이음, 60명이 함께
숨 쉬는 흐름)가 있는데, 음을 이어 붙이는 방식으로는 그게 나오지 않는다. 유튜브의 실제
연주 같은 소리를 원하면 길은 셋이다 — 공개 녹음(Musopen 등, 실제 악단의 퍼블릭 도메인
녹음), AI 음악 생성(Suno·Udio, 상업 이용은 유료 요금제), 곡 구매·의뢰. 어느 쪽이든 이
파일 하나만 바꾸면 된다.
