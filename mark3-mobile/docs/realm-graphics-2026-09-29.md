# 중세 캠페인 그래픽 구현 — 2026-09-29

생성 콘셉트 이미지를 배경으로 덮는 대신 실제 게임 지도의 3D 자산과 재질을 교체했다. 메인 화면 배경도 실제 게임 렌더링 캡처다.

## 구현

- Poly Haven CC0 성곽 모듈·수목·암벽 모델. 출처와 라이선스는 `public/realm/CREDITS.md`에 기록했다.
- 초지·암반·석재·회벽·목재·기와의 색상, 법선, 거칠기 맵. PC 2K, 작은 화면 1K를 사용한다.
- 연속 산맥, 경사에 따른 암반 혼합, 월드 좌표 기반 암반 재질, 그림자, 대기 원근감, 지도 밖 배경 지형.
- 수목은 근거리 입체 모델과 원거리 4방향 렌더 카드로 전환한다. 원본 약 200만 삼각형을 게임용 약 7만 삼각형으로 줄였다.
- 실제 성문·성벽·원형 탑과 내부 시가지, 축소된 군기, 병사 형상.
- 자산 로딩 안내, 지형을 피하는 카메라, 수도 확대 버튼. 화면 크기 변경으로 모델이 교체될 때 인스턴스 배치도 다시 적용한다.
- 자산 전체 약 140 MB(134 MiB). PC·모바일 양쪽 파일을 포함한 배포 용량이며 매번 전부 내려받는 용량은 아니다. 외부 자산 서버 없이 자체 호스팅한다.

## 검증

- TypeScript 타입 검사와 Expo 웹 export 통과.
- 11×11·21×21 지도: 결정적 생성, 상태 보존, 미탐험 정보 비노출, 공유 지형 정점, 면 방향, 모든 칸 레이캐스트 통과.
- 기존 medievalScene 테스트와 glTF 버퍼·이미지 참조, PC·모바일 재질 존재 검사 통과.
- 브라우저 PC 1440×900, 모바일 390×844 및 가로 화면 확인. 브라우저 오류 로그 없음.
- 실제 휴대폰 GPU·메모리 성능은 미검증이다. PC에서의 모바일 뷰포트 검증을 실기기 성능 측정으로 간주하지 않는다.

## 재현

`python tools/fetch-realm-assets.py`로 원본 자산을 받고 `node tools/prepare-realm-tree.cjs`로 수목 LOD를 생성한다. 원본 고밀도 수목은 무시된 `.realm-source/`에 저장된다. `node tools/check-realm-assets.cjs`로 결과의 참조 무결성을 확인한다.

이 구현은 실제 웹 3D 렌더러의 개선본이다. 콘셉트 이미지와 완전히 같은 영화 수준의 조명·건축 다양성이나 Total War 수준의 애니메이션을 구현했다고 주장하지 않는다.
