# 사실적 그래픽 작업 상태

지형·식생과 검·방패병 개선을 실제 Board3D에 연결했다. 전체 실사화가 끝난 상태는 아니다.

- 풀 3종 군락과 고사리: Poly Haven CC0 원본 형상·UV·색·법선·거칠기를 사용한다. 풀 glTF에서 빠진 원본 Alpha 맵을 별도 연결해 검은 카드 면을 제거했다.
- 숲 바닥: Forest Floor의 PC 2K / 모바일 1K 색·법선·거칠기를 초원과 혼합한다. 가까운 표면 텍셀 밀도를 높였다.
- 나뭇잎 자체 발광 제거. 근거리 입체 수목 예산은 PC 48 / 좁은 화면 20개(수종별)이며 원거리는 기존 LOD를 유지한다.
- 환경광: 촬영 HDR 하늘 반사와 카메라 주변 그림자.
- 검·방패병: piacenti Knight, CC BY 3.0. 원본 UV, 갑옷·검·방패 형상. 궁수·장창병·기병은 기존 모델이므로 추가 교체가 남았다.
- 성은 기존 건축이다. Vianden Castle by 333DDD (CC BY 4.0)의 다운로드가 내장 브라우저에서 차단되어 사용자 다운로드 파일을 기다리는 중이다.
- `?art=1&nature=1`은 게임과 동일한 지형·식생을 확인하는 고정 장면이다. 생성 이미지가 아니다.

검증: TypeScript, 웹 export, 11×11 및 21×21 장면 테스트, 전장의 안개·저장 상태 보존, 원본 자산 참조/버퍼 검사 통과. PC 실제 저장 게임과 자연 경관에서 콘솔 오류 없음. 화면 크기 지정이 지연 적용되어 실제 DOM 크기도 확인했다. 실기기 휴대폰 성능은 측정하지 않았다.
