# 협공 도입 — 2026-09-20

## 목표와 결과

목표: `massing`(병력 집중) 가중치가 학습에서 매번 0 으로 떨어지는 것을 고친다.
결과: **실패**. 협공 도입 후에도 `massing = 0.00` 그대로다.

## 왜 빗나갔나

진단은 맞았다. 원인은 **행동 횟수가 부대 수에 비례**하는 것이다.
40명 한 덩어리는 턴당 한 번, 10명 네 덩어리는 네 번 친다.

처방이 틀렸다. 협공은 "인접한 아군이 전력을 보탠다"는 기제라
**한 칸에 몰아넣는 것에는 오히려 페널티**다. massing 과 방향이 반대였다.

실측:

```
한 칸에 40명    → 협공 0.0,  총 전력 40.0,  공격 1번
두 칸에 20+20   → 협공 6.0,  총 전력 26.0,  공격 2번
```

한 번의 전투력은 뭉친 쪽이 세지만 쪼갠 쪽은 두 번 친다.
협공 6 으로는 그 격차를 못 메운다.

## 그래도 남긴 이유

협공 자체는 값어치가 있다.
- 전선을 이루고 나란히 서는 것에 값을 준다 (뭉치는 것과는 다른 미덕)
- 기존 포위 기제와 맞물린다
- 평가 기준 5/6 유지 (경제형 4.7% 만 미달, 기준선에서도 7.4% 로 노이즈 범위)
- 스택 크기가 최대 1~16 → 20~32 로 커졌다. 다만 이는 합병이 아니라
  targetArmy 가 20.2 → 25.5 로 오른 결과다.

학습 결과의 다른 변화:
```
explore     0.79 → 1.71   정찰 가치가 두 배 이상
targetArmy 20.23 → 25.52  병력을 더 많이 유지
castleAssault 16.05 → 20.60
```

## 다음에 시도한다면

행동 경제를 직접 건드려야 한다.
1. **지휘 한계** — 한 턴에 움직일 수 있는 부대 수에 상한. 원인을 그대로 겨냥한다.
2. 소부대 페널티 — 일정 규모 미만은 땅을 점령 못 하거나 사기가 낮다.
3. 합병 보너스 — 합칠 때 사기·기세가 오른다.

또는 `massing = 0` 을 답으로 받아들일 수도 있다.
"이 게임은 뭉치는 게임이 아니다"는 것도 설계상 유효한 결론이다.
