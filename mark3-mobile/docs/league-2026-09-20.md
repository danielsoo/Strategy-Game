# 리그 학습 1차 시도 — 2026-09-20

`npm run sim:league -- --gens 12 --matches 60`

## 결과: 채택하지 않음

리그 본체와 기존 단일집단 학습형을 300판 직접 붙였다(자리 회전, 나머지
세 자리는 손으로 만든 성격).

| | 승률 | 95% 신뢰구간 |
|---|---|---|
| 단일집단 학습형 | 47.3% | 41.8 ~ 53.0% |
| 리그 본체 | 36.0% | 30.8 ~ 41.6% |
| 그 외 3성격 | 16.7% | 12.9 ~ 21.3% |

신뢰구간이 거의 겹치지 않는다. 리그 본체가 실제로 더 약하다.

## 구현 결함

본체 승률이 세대마다 27~60% 로 요동쳤다. 수렴이 아니라 표류다.

1. **표본 부족** — 세대당 60판을 후보 4개가 나눠 가져 후보당 15판.
   15판의 95% 신뢰구간은 ±25%p 다. 좋은 후보가 아니라 운 좋은 후보를
   고르고 있었다.
2. **착취자 압박 과다** — 착취자가 본체를 50~67% 로 계속 추월했는데
   본체가 대응할 여유가 없었다. 매 세대 상대 구성이 바뀌어 개선 신호가
   묻혔다.

고치려면 세대당 판수를 최소 4배로 늘리고(후보당 60판 이상), 착취자 비중을
낮추거나 본체 평가를 착취자 없는 판으로 따로 재야 한다.

## 그래도 얻은 것

가중치 변화가 실제 발견을 담고 있다.

| | 단일집단 | 리그 |
|---|---|---|
| support | 0.00 | **0.30** |
| massing | 0.00 | **0.00** |
| terrain | 0.91 | 1.23 |
| castleAssault | 16.05 | 17.62 |

- **support 가 되살아났다.** 착취자가 약한 곳을 파고드니 아군을 돕는 것에
  값이 생겼다. 가설이 맞았다.
- **massing 은 착취자 압박 아래서도 끝까지 0 이었다.** "견제할 상대가
  없어서"가 아니라 이 게임에서 실제로 이득이 아니라는 뜻이다.
  대신 terrain 이 올랐다 — 뭉치는 대신 좋은 지형을 잡는 쪽을 골랐다.
  전투 모델에서 산·숲·요새가 방어에 최대 ×1.4 를 주므로 합리적이다.

병력 집중에 값을 주려면 기제를 새로 설계해야 한다. 예를 들어 큰 부대가
한 턴에 더 멀리 가거나, 인접 아군이 전투에 지원 사격으로 참여하는 식이다.
