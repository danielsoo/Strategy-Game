# 풍경 재구성 작업본

이전 HUD 변경은 사용자가 요청한 그래픽 품질에 미치지 못했다. 이번에는 UI가 아닌 장면을 수정했다.

- 건물의 최저 Y를 지면 기준으로 정규화하여 묻히던 건물 부분을 복원했다.
- 기존 벽 모듈의 왜곡된 축척을 제거하고, 석조 성벽·원형 탑·총안·성문·주탑을 새 메시로 구성했다. 재질은 기존 Poly Haven 석재의 색을 회색으로 조정한다.
- 성내 주거를 두 개의 순환 가로로 밀집시켰다. 성벽 안에 이웃 칸의 수목과 농가가 침범하지 않도록 한다.
- 숲 배치 후보를 칸당 38~57에서 145~204로 늘리고 수관 폭도 늘렸다. 원거리 수목은 기존 인스턴스 카드 방식을 사용한다. 부대 주위는 빈 공간으로 유지한다.
- 산의 능선 방향을 지역별로 연결하고 굴곡을 추가했다. 지형 분할을 12에서 18로 높였다.
- 잔디 텍스처를 서로 다른 크기와 각도로 혼합하고 농지를 어둡게 해 반복 무늬와 흰색 패치 같은 인상을 줄였다.

한계: 시안과 동일한 그래픽 완성이 아니다. 강·해안·항구가 없으며, 기존 주택 자산과 일부 절차적 병사 모델을 여전히 사용한다. 새 유료 자산이나 다운로드가 막힌 성 모델을 확보한 것처럼 표현하지 않는다. 모바일 실기기 GPU 성능은 별도 측정하지 못했다.

검증: TypeScript, 웹 export, 11·21 지도에서 상태 보존/정보 비노출/18분할 지형의 모든 칸 레이캐스트. 실제 브라우저에서 성곽 상세와 저장 게임을 확인.
