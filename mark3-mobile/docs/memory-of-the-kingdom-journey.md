# 왕국의 기억 · 여정

2026-09-29. 사용자가 “확정하고 싶은 멜로디 음과 타이밍은 없고 더 좋으면 얼마든지
수정해도 된다”고 명확히 했다. 이전의 멜로디 고정은 작업자가 좁게 해석한 것이며,
앞으로 음·리듬·화성·형식 모두 수정 가능하다. 이전 버전은 비교 자료로 보존한다.

이번 시안은 [북과 금관 편곡](memory-of-the-kingdom-epic.md)의 타악·금관을 유지하면서
주선율과 이에 응답하는 관악기도 다시 썼다.

- 첫 주제: 짧은 장식을 덜고, 아래로 내려앉았다가 올라오는 문장을 길게 연결.
- 중간 주제: 클라리넷의 긴 음과 쉼을 늘려 북의 전개에 앞서 대비를 만듦.
- 절정: 빠르게 여러 고음을 지나가는 대신 높은 음을 길게 펼친 뒤 해결.
- 호른·트럼펫·플루트·피콜로·오보에의 응답도 새 멜로디에 맞춰 동시 수정.
- 전체 길이와 큰 구조는 이번에는 유지: 80마디, 192.692초, 반복 연결.

주선율 파트의 이벤트는 직전 북·금관 버전 127개에서 115개로 바뀌었다.
멜로디를 더 매력적으로 만들기 위한 편곡 선택이며, 적은 음이 객관적으로 더 좋다는
뜻이나 청취로 우수함이 검증됐다는 뜻은 아니다.

## 파일

`public/music/memory-of-the-kingdom-journey`:

- `.mp3`: 전체 곡 3분 13초.
- `-theme.mp3`: 중후반 55초 미리듣기.
- `.wav` / `.flac`: 무손실 반복 원본.
- `-loop-check.mp3`: 8초 위치가 반복 경계인 16초 발췌.
- `.html`: 청취 및 이전 서사 편곡과 비교.

## 검증

26개 악기 파트, WAV/FLAC PCM 일치, MP3 디코딩 프레임 수 8,497,725 일치.
44.1kHz/24비트 스테레오. 통합 음량 -17.6 LUFS, LRA 9.7 LU, 트루피크 -1.8dBFS.
디지털 무음과 클리핑 없음. 반복 경계 차이는 곡 내부 파형 차이의 99백분위보다 작음.
실제 악단의 전체 공연 녹음은 아니며, 샘플 기반 제작의 한계는 이전 시안과 같다.

참고 작품은 놀란 감독의 **영화 오디세이**, 나니아, 어벤져스, 갓 오브 워, 왕좌의 게임.
참고 자료와 샘플 출처는 [북과 금관 기록](memory-of-the-kingdom-epic.md)에 있다.
