# 돌의 회랑 — 기존 곡과 별도로 만든 중세풍 관현악

2026-09-29. 요청: 전자악기 없이 실제 악단 같은 음색, 전체 오케스트라 악기 구성,
끝과 처음이 이어지는 새 곡. 기존 `theme.mp3`와 게임의 재생 설정은 변경하지 않았다.

## 듣기

- `public/music/cloister-of-stone.mp3`: 2분 17.143초, 256kbps, 간편 청취.
- `public/music/cloister-of-stone.wav`: 44.1kHz / 24비트 / 스테레오, 정확히 6,048,000프레임. 반복 재생용 원본.
- `public/music/cloister-of-stone.flac`: WAV와 같은 무손실 음원.
- `public/music/cloister-of-stone-loop-check.mp3`: 끝 8초 + 처음 8초. 8초 위치가 실제 반복 경계.
- `public/music/cloister-of-stone.html`: 별도 청취 페이지. WAV를 Web Audio 버퍼로 반복한다.

## 음악

D 도리안, 6/8, 4분음표 84bpm, 64마디. 열린 5도와 페달음, 긴 선율을 중심으로 썼다.
전자악기·신시사이저·드럼 머신은 없다. 하프의 두 박과 잉글리시 호른으로 시작해서
제1바이올린의 주제, 클라리넷의 응답, 호른과 금관의 확장, 처음 질감으로의 귀환을 거친다.
강한 완전종지나 페이드아웃을 만들지 않고 열린 D–A 위에서 반복한다.

## 편성

제1·제2바이올린, 비올라, 첼로, 콘트라베이스는 **각각 다른 현악 합주 샘플**이다.
독주 바이올린을 디튠해서 여러 번 복사한 합주가 아니다. 아래 인원은 편곡 규모의 목표이며,
실제 해당 인원을 고용해서 녹음하거나 각각의 연주를 모델링했다는 뜻은 아니다.

| 악기군 | 편성 규모의 목표 | 실제 악보에 포함된 파트 |
|---|---|---|
| 현악 | 18·16·12·10·8 = 64명 + 하프 1명 | 제1바이올린, 제2바이올린, 비올라, 첼로, 콘트라베이스, 하프 |
| 목관 | 12명, 보조 악기 포함 3관 구성 | 피콜로, 플루트, 오보에, 잉글리시 호른, 클라리넷, 베이스 클라리넷, 바순, 콘트라바순 |
| 금관 | 13명 | 호른 6, 트럼펫 3, 테너 트롬본 2, 베이스 트롬본 1, 튜바 1 |
| 타악 | 5명, 일부 악기 겸임 | 팀파니, 큰북, 작은북, 심벌즈, 트라이앵글, 실로폰 |

총 24개 샘플 파트. 큰북·작은북은 하나의 샘플 맵에서 별도 음으로 연주한다.
전 악기가 항상 함께 울리면 선율이 묻히므로 구간마다 출입을 다르게 했다.

## 음원 제작과 확인 범위

같은 현악 음은 마디를 넘어 이어 붙이고, 곡 끝과 시작에 같은 음이 있으면 반복 경계도
이어 붙인다. 관악기는 문장 끝에서 쉬고, 타악기는 가능한 경우 왼손·오른손 녹음을 교대한다.
샘플의 원본 튜닝 보정을 적용하며 인공적인 피치 흔들림이나 합성 발진기는 사용하지 않았다.
파트별 패닝, 저역 정리, 고역 완화, 짧은 공통 홀 잔향을 적용했다.
잔향은 원형 합성하여 지난 반복에서 넘어오는 울림을 처음부터 포함한다.

측정 결과는 `cloister-of-stone-analysis.json`에 저장된다. 샘플 피크 -1.80dBFS,
평균 RMS -18.23dBFS, 가장 작은 10ms 구간 RMS -25.88dBFS로 디지털 무음 구간은 없다.
FFmpeg 측정 통합 음량 -15.2 LUFS, LRA 3.1 LU, 트루피크 -1.8dBFS.
WAV와 FLAC는 디코딩한 PCM이 완전히 같고, MP3도 디코딩 후 6,048,000프레임임을 확인했다.
반복 경계의 좌우 샘플 차이는 곡 내부 차이의 99백분위보다 작다.
음량·파형 검사는 실제로 수행했으며, 사람이 듣고 자연스럽다고 판정한 결과는 아니다.

**한계:** 전체 악단이 함께 녹음한 연주는 아니다. 개별 녹음과 합주 샘플을 악보대로
재생한 시안이다. 실제 활의 음 사이 전이, 지휘에 반응하는 단원들의 상호작용까지 재현하지는
못하며, “AI 느낌이 전혀 없다”거나 실제 유튜브 공연과 동등하다고 보장하지 않는다.

## 재생성

Python 3.12에서 프로젝트 루트 기준:

```powershell
python -m pip install --target .music-cache/python -r tools/music/requirements-medieval.txt
python tools/music/prepare-medieval.py
python tools/music/render-medieval.py
```

`medieval-score.py`에 악보, `medieval-instruments.json`에 샘플과 믹스 설정,
`render-medieval.py`에 전용 렌더러가 있다. 시드는 고정했다. 의존성·원본 샘플은 게임에
포함하지 않고 `.music-cache/`에만 저장한다. `render.js`, `score.js`, `theme.mp3`는 보존했다.

렌더러는 이 곡에 필요한 SFZ 기능만 구현한다. 범용 SFZ 엔진이나 실시간 게임 엔진은 아니다.
