# 대련 동작 5: 골격 중심과 실제 파일 축척부터 수정

이전 버전의 수치 검사는 팔의 모양이 자연스럽다는 증거가 아니었다. 사용자가 제공한 화면에는 손목·팔꿈치 꺾임이 남아 있었다.

## 확인한 원인

- 원본 기사에는 골격이나 애니메이션이 없다. 검 끝을 표적으로 끌어당기는 임시 IK가 팔 전체의 자세를 결정했다.
- 원본 장갑 시작점은 기존 손목 중심보다 몸 가까이에 있었다. 새 관절 중심은 키 1.75 기준 어깨 `(±0.24,1.35,-0.075)`, 팔꿈치 `(±0.425,1.21,-0.075)`, 손목 `(±0.565,1.12,0.035)`이다.
- 방패 분류는 원본 좌표의 고정 수치 20/40을 사용했다. 실제 glTF 노드는 0.0299875 배 축척을 가진다. 브라우저에서 방패가 신체로 분류되어 팔과 함께 휘었다. Node 테스트 로더가 노드 축척을 누락해 이 문제를 놓쳤다.

## 변경

- 방패 분류를 모델 높이에 대한 비율로 수정하고, 테스트 로더에도 glTF 노드 축척을 적용했다.
- 대련은 Quaternius CC0 클립을 재생한다. 원본의 어깨·팔꿈치·몸통 회전을 유지하면서 기사 체형으로 옮긴다. 검 끝을 맞추는 IK는 대련 경로에서 사용하지 않는다.
- 원본의 열린 손 대신 원본 골격으로 쥔 손을 추출했다. 검 손잡이와 닫힌 주먹을 같은 좌표계에 고정했다. 과도한 손목 플릭은 아래팔에서 12도까지 제한한다.
- 원본 검의 큰 곡선 가드는 직선 십자 가드를 갖춘 한손검으로 교체했다. 방패는 별도의 강체 메시로 분리하고, 손잡이 뒷면이 아닌 문장 앞면으로 막도록 방향을 바로잡았다.
- 접촉 전에 방패를 세우고, 막힌 베기는 접촉 클립에서 반동·회수로 이어진다. 두 번째 베기는 별도의 클립을 사용한다. 세 번째 교환은 방패가 낮아진 빈틈에 피격 반응을 연결한다.
- 검토 화면과 실제 맵의 대련은 같은 컴포넌트를 사용한다. 동작 6에서는 쓰러짐·소멸을 포함해 13.2초로 늘리고 기존 전투 종료 대기 상수도 함께 늘어난다.

## 재생성·검증

원본 ZIP과 glTF는 `.realm-source/animation/`에 보관한다. `node tools/prepare-knight-motion.mjs`로 필요한 6개 클립의 60 Hz 관절 데이터와 손 메시를 재생성한다. 출처와 라이선스는 `public/realm/knight/CREDITS.md`에 기록했다.

## 동작 6: 사망과 먼지 소멸

- 마지막 피격 뒤 패배자만 `Death01`에 부드럽게 연결한다. 쓰러진 몸통·골반·머리가 지면을 지지하도록 접촉 높이를 보정한다.
- 8.6초부터 2.3초간 몸·손·검·방패를 동일한 공간 함수로 절단한다. 일반 재질과 그림자 재질 모두 같은 소멸 경계를 사용한다.
- 변형된 메시의 실제 표면 넓이에 비례해 1,800개 입자를 배치한다. 경계가 통과하는 시각에 방출해 바람·난류·감쇠를 적용한다. 시간만으로 계산하므로 일시정지·단계 이동·반복 재생에도 동일하게 보인다.
- 패배자의 식별 표시는 사망 때 숨기고, 생존자는 남는다. `사망 모션`은 마지막 피격부터 재생하고 `먼지 소멸`은 중간 순간을 정지해 보여준다.
- 회귀 검사에는 사망 시 관절 연속성, 몸통의 지면 접촉, 승패 조합, 입자 수명·초기화 및 재질 복구를 추가했다.

## 동작 7: 지면과 장비 접촉

이전의 발·몸통 기준점과 칼날 65% 지점만 맞추는 검사는 갑옷 끝·검 끝의 관통을 검출하지 못했다.

- `terrainField.surfaceHeight`는 CampaignLand의 18분할 삼각 격자를 그대로 보간한다. 높이 노이즈 함수와 렌더링 면의 차이를 없앴다.
- `duelContacts`는 실제로 그리는 정점만 모아, 병사 한 명당 몸·장갑·검·방패 14,786개 정점으로 접지 높이를 정한다. 갑옷 두께와 누운 방패를 포함한다.
- 방패 메시에서 만든 볼록 다면체와 칼날 양쪽 날의 선분을 검사한다. 접근·접촉·회수 전체를 검사하고, 팔·손목은 그대로 유지한 채 간격을 보정한다.
- 상대의 흉갑·골반·투구는 보호 부피를 두어 무기와 방패의 깊은 관통을 막는다. 실제 갑옷 표면의 삼각형끼리 푸는 범용 강체 물리 시스템은 아니다.
- 검 회수는 자기 방패 안으로 계속 휘두르지 않도록 접촉 궤도로 되돌린다. 사망 시 검 팔을 바깥으로 열어 자기 방패를 관통하지 않도록 했다.
- 검토 화면과 전략 지도 모두 같은 접촉 함수를 사용한다. `tools/check-duel-contacts.ts`는 120Hz 전 구간·양쪽 선공/승패·기복 지형·지도 축척/회전·실제 지형 삼각형 높이 일치를 검사한다. 단일 중간점의 방패 접촉 검사는 전체 날 검사로 대체했다.

`tools/check-authored-combat.ts`는 양쪽 선공/승패 조합에서 관절 유한성, 12도 손목 제한, 주먹과 손잡이 고정, 발 지지, 전환 연속성, 실제 방패 메시와 접촉 위치를 검사한다. 두 차례 방패 접촉 오차는 약 0.35 mm / 0.41 mm다. 이 검사는 자연스러움에 대한 사용자 평가를 대신하지 않는다.

실제 브라우저에서 사선베기·반격·준비·회수와 손목 확대를 검토한다. 여전히 수작업으로 체형에 맞춘 리타기팅이며, For Honor의 전용 모션캡처·캐릭터 리그와 동등한 결과라고 주장하지 않는다.
