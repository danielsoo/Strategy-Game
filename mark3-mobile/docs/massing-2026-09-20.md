# 뭉치기는 왜 안 살아나는가 — 세 번의 측정

2026-09-20

## 배경

자가대전 학습은 `massing`(병력을 한 칸에 모으는 성향)을 **매번 0 으로** 내렸다.
협공을 넣어도, 측면 지원을 넣어도 살아나지 않았다. 원래 이 게임을 만든 이유
중 하나가 "집중된 병력이 의미를 가져야 한다"였으니, 그냥 넘길 수 없는 일이었다.

## 1. 자리 수 때문인가 — 아니다

전선이 하나면 뭉치는 게 맞고 셋이면 흩는 게 맞다는 가설. 1대1 학습이
`massing` 을 상한(4.00)까지 올린 것이 근거처럼 보였다.

200판씩, 무작위 기준선은 자리 수에 따라 다름:

```
            1대1(9x9)        3인(11x11)       5인(11x11)
massing 0.0   38.0%            32.5%            78.0%
massing 0.5   29.5%            29.5%            57.5%
massing 1.0   39.0%            20.0%            42.0%
massing 2.0   43.0%            19.5%            18.5%
massing 4.0   37.5%            17.0%            17.0%
```

1대1에서는 **차이가 없고**(구간이 전부 겹침), 3인·5인에서는 단조롭게 나빠진다.
자리 수가 몇이든 최적값은 0이다.

그러면 1대1 학습이 4.00 까지 올린 것은 실력이 아니라 편승이었다 — 그 축으로
지형이 평평하니 다른 변이에 딸려 올라간 것이다. 다른 시드는 0.67 이었다.

## 2. 행동 경제 때문인가 — 아니다

행동 횟수가 부대 수에 비례하니 쪼개는 쪽이 언제나 이긴다는 가설. 10명 넷은
턴당 네 번 치고 40명 하나는 한 번 친다. 그래서 명령 수를 거점 수에 묶는
**지휘 용량**을 넣고 재봤다 (`commandBase`, `commandPerHub`).

판은 망가지지 않았다:

```
  설정                     평균 턴   턴제한   공격/판   속국/판
  제한 없음 (지금 규칙)       61.3     9.2%     34.0     2.33
  기본 3 + 거점당 2          66.2    11.7%     31.1     2.46
  기본 2 + 거점당 1.5        64.3    11.7%     32.8     2.58
  기본 5 + 거점당 3          65.8    11.7%     30.9     2.23
```

그런데 `massing` 의 최적값은 꿈쩍도 하지 않았다 (150판씩):

```
  설정                  massing 0   massing 0.6  massing 1.5   massing 3
  제한 없음               72.0%        47.3%        28.0%       17.3%
  기본 3 + 거점당 2        78.0%        52.0%        34.7%       17.3%
  기본 2 + 거점당 1.5      73.3%        51.3%        41.3%       17.3%
  기본 5 + 거점당 3        84.0%        54.7%        32.0%       16.7%
```

어느 설정에서든 0 이 최선이다. 가설 기각.

다만 명령 수를 제한했을 때 학습형 승률 자체가 72% → 84% 로 올랐다. 이때
두 가지를 같이 바꿨으므로(명령 한도 + '값어치 큰 수부터 둔다'는 순서 규칙)
어느 쪽이 효과인지는 따로 갈라야 한다. `sim/command.ts` 에 순서만 켜는
설정을 넣어뒀다.

## 3. 협공이 이미 그 일을 하고 있다

남은 설명 — 이 게임에는 집중 기제가 이미 있다. **협공**이다. 인접한 아군이
전력을 보태주니, 두 부대가 나란히 서면 합친 것과 같은 힘으로 싸우면서
공격은 두 번 한다. 한 칸에 포개는 것은 그래서 순손해다.

그렇다면 협공을 끄면 뭉치기가 살아나야 한다. → `sim/concentration.ts`

## 무엇을 배웠나

`massing = 0` 은 결함이 아니라 이 게임이 집중을 **공간으로** 표현하기 때문일
가능성이 크다. 한 칸에 쌓는 것이 아니라, 전선을 따라 나란히 서서 서로를
받쳐주는 방식이다. 문명의 '죽음의 스택'이 싫어서 시작한 게임이니, 그쪽이
오히려 원래 의도에 맞는다.

가중치 하나가 0 인 것을 보고 두 번(협공, 측면 지원) 손으로 고치려 들었는데,
그때마다 필요한 것은 수정이 아니라 측정이었다.
