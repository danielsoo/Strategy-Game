# 팔 관절·갑옷 수정 4 — 2026-09-30

사용자가 보여 준 회수 자세에서 어깨 갑옷과 위팔이 함께 접혀 보였다. 이전 검증은 검·방패 접촉, 아래팔 회전 연속성 위주였고 위팔과 갑옷의 변형을 놓쳤다.

## 원인과 수정

- 원래 스키닝은 가로 좌표만으로 위팔/아래팔을 구분했다. 넓은 어깨 갑옷 끝이 아래팔에 배분되었다. 어깨→손목 중심선에 투영한 거리로 가중치를 다시 나누어, 위팔 위에 있는 갑옷은 위팔을 따른다.
- 칼날 접촉점으로 팔을 풀던 해법에서 실제 팔꿈치 굽힘이 약 162.5도에 이르렀다. 최대 125도 제한을 넣고, 이를 넘는 표적은 손목을 비트는 대신 어깨에서 바깥 방향으로 보정한다. 현재 공방에서 측정한 최대는 약 114.6도다.
- 고정된 팔꿈치 기준점이 칼끝 방향과 일직선에 가까워지는 구간이 있었다. 기준점을 몸통을 따르는 바깥/아래/앞 방향으로 바꾸고, 관절 해법의 완전 접힘/폄 경계에도 여유를 두었다.
- 위팔의 방향만으로 최단 회전을 고르면 반대 방향에서 회전축이 불안정해진다. 실제 위팔·아래팔의 굽힘 면까지 포함한 회전 프레임으로 연결했다.
- 방패의 회전값을 손에 그대로 복사하던 부분을 수정했다. 방패 손과 아래팔은 같은 회전을 사용하고, 방패 면은 별도 뼈로 기존 접촉 방향을 유지한다.
- 베기 곡선의 마지막 제어점을 앞으로 옮겨 몸 가까이 파고드는 궤적을 줄였다.

## 확인

`tools/check-army-animation.ts`에 실제 어깨 갑옷 정점의 관절 연결, 팔꿈치 최대 굽힘, 방패 손목 정렬, 위팔 회전 연속성 검사를 추가했다. 두 선공·승자 조합의 전체 동작을 검사하며, 기존 검/방패 접촉과 120Hz 자기/상대 방패 관통 검사도 통과한다. 측정 최대: 아래팔 약 4.25도/120Hz, 위팔 약 11.86도/120Hz.

TypeScript와 웹 export 통과. 브라우저에서 사선 접촉, 횡베기 직전, 회수 자세를 확대 확인했다. 이 검증은 기존 정적 모델의 절차적 리깅 범위이며 전문 모션캡처나 손가락 전체의 해부학적 검증을 뜻하지 않는다.
