# 중세 캠페인 지도 적용

승인된 사실적인 전략 지도 시안의 방향을 실제 Three.js 지도에 적용했다. 생성 시안을 배경으로 붙인 것이 아니라 확대·이동·선택 가능한 지형 메시를 바꾼 것이다. 시안의 고해상도 재질·건축물 수준까지 구현한 것은 아니다.

- 개별 육각 기둥을 공유 정점을 가진 연속 지표면으로 교체했다. 산의 높이와 색은 주변으로 이어지고 성 주변은 완만해진다.
- 같은 나라 내부의 육각 테두리를 없애고 외곽 국경만 지형을 따라 표시한다. 선택·이동 가능 표시는 기존 칸 단위를 유지한다.
- 성곽 주변에 목골 가옥을 배치하고 박공지붕·돌의 이음매를 더했다. 숲은 작은 수관 무리가 겹치도록 만들었다.
- 병사는 작은 대열로 표현한다. 표시된 병력 수와 실제 게임 규칙은 그대로다.
- 지형은 플레이어의 현재 시야와 정찰 기억만 사용한다. 관전에서만 모든 지형이 공개된다.

## 확인

- `node node_modules/typescript/bin/tsc --noEmit`: 통과.
- `node node_modules/tsx/dist/cli.mjs tools/check-realm-scene.ts`: 11×11·21×21에서 결정성, 상태 보존, 미탐험 정보 비노출, 공유 정점, 위쪽 면 방향, 전체 칸 수직 레이캐스트 매핑 통과.
- `node node_modules/expo/bin/cli export --platform web --output-dir .ui-preview`: 통과.
- 브라우저 1440×900: 전체 지형, 국경, 부대 선택, 확대와 초기화 확인.
- 브라우저 390×844 / 844×390: 반응형 배치와 확대 확인. 가로 화면 문서 폭 844, 캔버스 586×372. 콘솔 오류 없음.
- 실제 휴대폰 GPU 성능과 두 손가락 조작은 미검증. 데스크톱 브라우저의 화면 크기를 바꾸어 확인했다.
