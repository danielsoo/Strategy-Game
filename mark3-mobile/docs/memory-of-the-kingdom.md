# 왕국의 기억 — 멜로디 재작곡

2026-09-29. 이전 시안의 멜로디가 아쉽다는 피드백에 따라, 사용자가 선택한
**웅장하고 애틋한 왕국의 주제**로 선율과 화성을 새로 썼다.
기존 게임 음악과 `cloister-of-stone.*`는 덮어쓰지 않았다.

## 들어볼 파일

- `public/music/memory-of-the-kingdom-theme.mp3`: 첫 주제 전체, 약 37초.
- `public/music/memory-of-the-kingdom.mp3`: 전체 곡, 2분 27.69초.

- `memory-of-the-kingdom.html`: 미리듣기, 연속 반복, 이전 시안 비교.

## 바꾼 음악

짧은 8마디 선율의 반복에서 16마디의 질문·응답 구조로 바꿨다.
D–F–E–D에서 A로 내려앉는 동기를 만든 다음, 응답에서 더 높은 음으로 펼친다.
중간에는 긴 음을 중심으로 한 클라리넷의 두 번째 주제가 나오고,
재현부에서는 주제의 뒤쪽 8마디를 다시 써서 절정을 한 번 만든다.
마지막은 목관과 열린 D–A로 돌아오며 다음 반복을 준비한다.

D 단조, 6/8, 4분음표 78bpm, 64마디. 자연단음계에 종지의 C♯를 쓴다.
일률적인 근음 이동 대신 전위화음과 내려가는 저음으로 선율을 받친다.
제1바이올린을 앞에 두고 제2바이올린·비올라·하프의 음량과 밀도를 낮췄다.
목관이 모든 선율을 상시 겹치지 않고 문장 끝을 보완하게 했다.

| 구간 | 시작 | 내용 |
|---|---|---|
| 1–4마디 | 0:00 | 잉글리시 호른으로 동기를 바로 제시 |
| 5–20마디 | 0:09 | 바이올린의 16마디 첫 주제 |
| 21–36마디 | 0:46 | 낮은 클라리넷에서 시작하는 두 번째 주제 |
| 37–52마디 | 1:23 | 바이올린·호른의 재현, 높은 음역의 변주 |
| 53–60마디 | 2:00 | 오보에와 바이올린의 잦아드는 응답 |
| 61–64마디 | 2:18 | 목관과 하프, 반복으로 연결 |

이전 요청의 악기 구성은 모두 유지했다. 제1·제2바이올린, 비올라, 첼로,
콘트라베이스, 하프, 목관 8종, 호른, 트럼펫, 테너·베이스 트롬본, 튜바,
팀파니, 큰북·작은북, 심벌즈, 트라이앵글, 실로폰이 24개 파트에 들어 있다.

## 검증

- WAV / FLAC의 디코딩 PCM 일치. MP3 디코딩도 6,513,231프레임으로 원본과 동일.
- 통합 음량 -17.1 LUFS, LRA 6.7 LU, 트루피크 -1.8dBFS.
- 무음 끊김과 클리핑 없음. 반복 경계 샘플 차이는 내부 차이의 99백분위보다 작음.
- 전체 24개 파트의 음표와 샘플 음역 확인.

수치는 파일 검사 결과이며, 음악의 매력이나 실제 공연 같은 자연스러움을 증명하지 않는다.
이 곡도 녹음 샘플을 편곡한 시안이다. 라이브 악단의 전체 합주 녹음은 아니다.
샘플은 [Sonatina Symphonic Orchestra](https://github.com/peastman/sso),
Mattias Westlund 및 기여자, [CC Sampling Plus 1.0](https://creativecommons.org/licenses/sampling+/1.0/).

## 재생성

샘플과 의존성 준비는 [첫 시안 문서](cloister-of-stone.md)를 따른다.

```powershell
python tools/music/render-medieval.py --score kingdom-score.py --name memory-of-the-kingdom --excerpt-bars 4 20
```

`kingdom-score.py`에 새 악보와 믹스 조정을 두었다. 렌더러는 출력 이름을 받아
이전 파일을 보존한다. 시드와 샘플 소스 커밋은 측정 JSON에 기록한다.
