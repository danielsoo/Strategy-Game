# 왕국 연대기 — 중세 화면과 반응형 구성

사용자가 확정한 음악의 분위기를 로딩·메뉴·설정·게임 화면으로 이어갔다.
아기자기한 육각 지도의 가독성을 유지하면서 석조 성채·목골 가옥·수확한 밭·돌담을 더했다.
엔진·AI·경제·저장 형식에는 변경이 없다.

## 화면

- `RealmMenu`: PC(가로 960 이상, 높이 600 이상)는 성채 전경과 원정 준비를 좌우로,
  작은 화면은 세로 스크롤로 배치한다. 시작·이어하기·길잡이·규칙·판 설정은 기존 동작이다.
- `RealmLoading`: 실제 GameScreen 모듈을 불러오는 동안 같은 전경과 진행 표시를 쓴다.
  가짜 진행률이나 강제 대기 시간은 없다.
- `RealmBackdrop`: 프로젝트 안에서 작성한 SVG 전경. 외부 이미지·웹폰트 다운로드가 없다.
- `realmTheme`: 먹색·양피지·황동색과 제목 글꼴. 설정·외교·속국·전투·결말·길잡이 색상을 맞췄다.
- 설정을 소리/게임 진행 탭으로 나누고, 눈금·스위치에 접근성 상태를 넣었다.
  높이가 낮으면 본문만 스크롤하고 닫기/초기화는 유지한다.
- 다른 대화창에도 화면 높이 제한과 스크롤을 적용했다. 지도의 국가 식별색은 유지한다.
- 확정 배경음은 `/music/memory-of-the-kingdom-ensemble.mp3`. 첫 입력 후 자동 반복하며
  기존 음량과 음소거 설정을 따른다.

## 지도

원형 성탑·각진 지붕·성문 철창·부벽, 평야의 작은 가옥·밭·돌담을 추가했다.
석재·땅의 명암은 셰이더에서 계산하며 새 텍스처 요청은 없다. 모든 장식은 인스턴스 렌더링이다.
휴대폰 크기에서는 DPR 상한 1.25, 그림자 1024, PC는 DPR 상한 1.5, 그림자 2048.
작은 지도 위에서는 긴 설명을 숨겨 조작 버튼과 지형을 볼 공간을 확보했다.

## 검증

- `node node_modules/typescript/bin/tsc --noEmit` 통과.
- `node node_modules/expo/bin/cli export --platform web --output-dir .ui-preview` 통과.
- `node node_modules/tsx/dist/cli.mjs tools/check-realm-scene.ts` 통과.
  11×11·21×21에서 장식 결정성, 게임 상태 보존, 미탐험 정보 비노출, 유효 좌표·크기를 확인했다.
- 실제 인앱 Chromium 브라우저의 390×844, 844×390, 1440×900 화면에서 확인했다.
  시작/이어하기, 설정 진입 및 탭 전환, 음량/음소거, 외교 닫기, 지도 확대, 턴 1→2 진행.
- 가로 설정 창은 본문 스크롤 및 하단 닫기 버튼 노출을 확인했다.
- 화면 기록: `docs/ui-2026-09-29/`. 실제 휴대폰 하드웨어·Safari·네이티브 APK는 검증하지 않았다.
  직접 조작하지 않은 전투/속국/결말의 모든 상태까지 시각 검증했다고 주장하지 않는다.

기존 설치에 누락된 package.json의 mongodb 의존성을 복원했다. 동적 모듈 로딩을 위해
TypeScript module을 esnext로 지정했다. app.json의 방향은 세로 고정에서 자동으로 변경했다.

## 로컬 확인

메인 반영에는 실제 게임에서 사용하는 확정 MP3와 악보·도구·기록을 포함한다.
이전 시안 및 무손실 WAV/FLAC은 작업 PC에 보존하며 배포에는 포함하지 않는다.
맥북 등 다른 기기에서는 로컬 주소 대신 기존 배포 주소
`https://strategy-game-umber.vercel.app`을 사용한다.

```powershell
npm run web
```

현재 검증 빌드는 `http://127.0.0.1:8790/`에서 제공한다. 서버가 종료되면 다시 실행해야 한다.
정적 미리보기는 다음 명령으로 생성/실행할 수 있다.

```powershell
node node_modules/expo/bin/cli export --platform web --output-dir .ui-preview
python -m http.server 8790 --bind 127.0.0.1 --directory .ui-preview
```
