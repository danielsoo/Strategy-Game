# 정의와 공포, 떠도는 무리, 그리고 두 길의 저울

외교(docs/diplomacy-2026-09-26.md) 다음 단계. 규칙을 다 정한 뒤 한 번에 쟀다 —
중간에 바뀌는 규칙으로 판정을 돌리지 않았다.

## 무엇을 넣었나

**평판 (src/engine/reputation.ts)**
- 정의·공포 모두 0 에서 시작한다. 저절로 돌아오지 않는다(자연 감소 없음).
- 한쪽이 다른 쪽을 15 넘게 앞서면 나라의 성격이 바뀐다(정의의 나라 / 공포의 나라 /
  성향 없음). 바뀔 때 연대기에 한 줄이 남는다 — 판타지 연대기 투의 대사.
- 모든 변화는 `adjustRep` 하나를 지난다. 공포는 살려주거나 봐줄 때·선한 일을 할 때
  내려가고, 정의는 옳은 일을 할 때 오른다.
- 전쟁 중 약탈(적과 싸우며 챙기는 것)은 평판을 건드리지 않는다. 전쟁과 상관없는
  마을을 터는 것(행군 사건)만 건드린다.
- 충성(마음)과 복종을 나눴다. 정의로운 종주국은 충성이 오르고, 두려운 종주국은
  명령이 먹힌다(복종·반란 억지). "정의로우면 충성이 높다" 하나로 끝내지 않았다.

**행군 사건 (src/engine/encounters.ts)** — 사건은 모두에게 같다. 반응이 성격에 기운
확률로 갈린다(환영 0.6+3J · 경계 1.2 · 굴복 0.6+3F · 독 0.2+1.5F(1−J)). 반응마다
대처가 여럿이다. 용병·도적 사건은 없앴다 — 무리와는 부대로 직접 만난다.

**떠도는 무리 (rules.ts stepNeutrals)** — 도적·용병이 저마다 움직인다.
- 선악(-100~100)은 무리 **자신이 한 일** 로만 바뀐다. 털면 악, 털 수 있었는데
  지나가면 선. 나라가 살려 보내도 무리의 선악은 그대로다.
- 공포의 이득: 두려운 나라의 땅은 털리지 않는다(공포만큼 억지). 그건 선택이
  아니므로 선악도 그대로다.
- 부대가 옆에 가면: 계약(선할수록 싸고 잘 받아들인다) · 물러나라(세력비와
  공포가 클수록) · 공격 · 그냥 둠. AI 도 같은 네 가지를 쓴다.

## 두 길의 저울 (sim/paths.ts)

같은 학습형 AI 다섯에게 길(정의/공포)만 다르게 주고 자리를 번갈아 준다.
나라당 승률의 비(정의/공포)가 1 이면 반반이다.

**차이를 만든 것은 평판의 크기가 아니라 병합 대 속국이었다.** 저울추(정의·공포가
주는 이득 전체)를 0 으로 꺼도 비는 0.35~0.45 였다. 길이 닿는 선택을 하나씩 끄면
'병합 대 속국' 만 비를 1 근처로 옮겼다. 병합이 진 나라의 군대까지 통째로
삼켜서 눈덩이가 됐기 때문이다. 그래서 셋을 함께 바꿨다:

| 값 | 뜻 |
|---|---|
| annexArmyKeep 0 | 병합하면 군대는 도적이 되어 흩어진다 |
| annexUnrestTurns 20 | 병합한 땅은 20턴 수입이 없다 (판 크기로 늘리지 않는다) |
| conquestLoyalty 70 | 살려둔 속국은 은혜로 충성 70 에서 시작 |
| justiceWeight 1.3 | 정의의 저울추 (공포 1) |

버린 것 (11x11, 출발 규칙 위에서 하나씩): 수입 끊기만 10/20/30/50턴 → 0.49/0.34/
0.39/0.43 · 충성만 60/80/100 → 0.37/0.47/0.40 · 흡수 몫만 0.5/0.3/0 → 0.48/0.43/0.63.
불안을 판 크기로 늘리면 21x21 에서만 병합이 지나치게 불리해졌다.

### 최종값에서 (학습 뒤, 시드 여럿)

| 판 | 시드별 승률비 | 합친 나라당 승률 (정의 / 공포) |
|---|---|---|
| 11x11 · 200판 | 0.71 (4242) · 0.83 (777) · 0.83 (31337) · 0.77 (90210) | 17.6% / 22.4% → 0.79 |
| 21x21 · 100판 | 1.04 (4242) · 1.22 (13337) · 1.33 (90210) | 21.7% / 18.3% → 1.19 |

작은 판은 공포가, 큰 판은 정의가 앞선다. 11x11 은 합치면 판마다 2000자리라
구간(±1.7%p)이 겹치지 않는다 — 진짜 기울기다. 21x21 은 750자리(±2.9%p)라
경계선이다. 짧은 판(55턴)에서는 정의의 길 가운데 '정의의 나라' 가 되는 게
34% 뿐이고(21x21 은 44~52%), 정의의 이득이 쌓일 시간이 없다. 공포는 병합 한 번에
+4 라 빨리 붙는다. **공포는 빨리 이기고 정의는 오래 이긴다** — 이 모양은 게임으로서
나쁘지 않다고 보고 여기서 멈췄다. 두 길 모두 기준선 20% 에서 ±2.5%p 안이다.

### 다듬으려다 버린 것

- **정의 저울추 1.6**: 11x11 0.75 · 0.75 · 0.49 · 0.87 (합쳐 0.71, 1.3 보다 나쁘다),
  21x21 1.22 · 0.69 · 1.13 (합쳐 0.99). 저울추는 손잡이가 아니다 — 다시 확인.
- **속국 영향력 가중 0.5 → 0.7 / 0.85**: 11·21 모두 0.5 와 소수점까지 같았다.
  배선을 봤더니 `dominanceShare` 가 0 이라 영향력 승리 자체가 꺼져 있다 —
  이 값은 지금 어디에도 쓰이지 않는다. 끊긴 배선이 아니라 손잡이가 없는 것.
- 11x11 에서 선택을 하나씩 끈 것(최종값 위, 시드 4242 · 90210):
  병합 대 속국 1.25 · 1.06 / 무리 대하기 1.04 · 0.69 / 배신 0.74 · 0.53 /
  행군 사건 0.77 · 0.75 / 속국 다루기 0.68 · 0.63. 남은 기울기도 전부 병합 대 속국이다.
  다음에 손댈 곳은 거기다(예: 불안한 땅이 반란의 불씨가 되게).

sim:paths 의 21x21 턴제한은 6~12% 로 sim:eval(약 3%)보다 높다. 길을 고정하면
두려운 나라끼리·정의로운 나라끼리 서로 먹지 못하고 버티는 판이 생긴다.

## 다시 학습했고, 버렸다

`sim:learn --sizes 11,21 --pop 14 --gens 8 --games 350` (세대당 350판).
후보는 판정을 통과했지만(11x11 6/6 두 묶음, 21x21 6/6 두 묶음) 옛 값과 붙이면 졌다:

| | 옛 값 | 새 값 |
|---|---|---|
| 11x11 맞대결 (200판, 시드 4242 / 777) | 25.2% / 24.4% | 14.8% / 15.6% |
| 21x21 맞대결 (120판, 시드 4242 / 13337) | 21.0% / 20.3% | 19.0% / 19.7% |
| 손으로 만든 성격 넷 상대 (sim:eval 학습형 기준점) | 25~36% | 18~27% |

거울 자가대전에서만 이기는 값이었다. 옛 값을 둔다(ai.ts 주석에 후보 값째로 적었다).
`--games 60`(1인당 4.3판)으로 먼저 돌린 것은 fort 3.33 같은 값이 나왔고 5인 검증
15% — 운을 골랐다. 두 학습의 5인 검증이 모두 15.0% 로 같았는데, 시드 하나 60판
(9승)이라 우연으로 본다. 도장은 어긋난 채(0be0f9d6 → 94ee042c)로 둔다 —
하네스가 깨지지 않았기 때문이다.

## 판정 (sim:eval, 옛 가중치, 최종 규칙)

| 판 · 시드 | 결과 | 턴 · 턴제한 · 공격 | 손 성격 최고 / 최저 | 자리 편차 |
|---|---|---|---|---|
| 11 · 4242,13337,90210 | 6/6 | 47.2 · 0.0% · 43.8 | 22.2 / 12.2 | 4.7 |
| 11 · 7,777,31337 | 6/6 | 46.8 · 0.0% · 44.7 | 25.9 / 13.1 | 2.7 |
| 21 · 4242,13337,90210 합침 | 6/6 | 98.0 · 2.8% · 90.0 | 24.7 / 12.9 | 3.2 |
| 21 · 7,777,31337 합침 | 6/6 | 102.0 · 2.8% · 91.9 | 24.2 / 13.8 | 3.1 |

21x21 은 시드마다 260판씩 따로 돌려 합쳤다. 시드 하나만 보면 자리 편차가 13337 에서
6.9%, 7 에서 5.8% 로 문턱(5%p)을 넘는다 — 260판짜리 한 자리의 구간이 ±5%p 라
한 시드로는 이 판정을 할 수 없다. 합치면 3.2 · 3.1.

외교 이전 21x21 은 최고 성격 37.5%(5/6), 외교 1차 뒤 33.5%(겨우 6/6)였다.
지금은 24~25% 로 여유가 넓다. (버린 학습 후보는 같은 판에서 공격 61~68회,
옛 값은 87~94회 — 옛 값이 더 싸운다.)
