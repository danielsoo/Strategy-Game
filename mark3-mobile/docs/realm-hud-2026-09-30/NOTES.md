# 시안 기준 HUD와 병력 식별성

- 병사 크기를 기존 .031~.034에서 .077~.085로 약 2.5배 확대했다. 대열 간격도 같이 넓혔다. 시각적 인원은 최대 24명이며 실제 병력 숫자·규칙은 변경하지 않았다.
- 부대 위에 화면 크기 기준 문장기를 표시한다. 내 군대·중립·적군·동맹·휴전 명칭과 소속 색을 함께 표시하고 선택 시 금색 테두리를 강화한다. 문장기 클릭은 기존 칸 선택 동작으로 연결된다.
- 3D 일반 플레이는 좌측 사이드바 대신 전면 지도, 상단 국정 바, 좌하단 선택 부대 카드, 우하단 턴 종료와 미니맵을 사용한다. 길잡이·관리자·2D 화면은 기존 기능을 유지한다.
- 미니맵은 Ground의 시야/기억 정보만 사용한다. 미발견 적 소유권·병력은 표시하지 않는다. 클릭하면 카메라를 이동한다.
- 시안에만 존재하는 목재·식량 등 가짜 자원 수치나 240명 환산 수치를 넣지 않았다. 강·항구·해안·새 성 모델은 이 변경에 포함되지 않았다.

검증: 타입 검사와 웹 export, 장면 테스트, 11×11·21×21의 상태 보존·시야 비노출·레이캐스트 통과. 319×583와 390×844에서 가로/세로 문서 넘침 없음. 390×844에서 문장기로 부대를 선택하고 병력 카드·턴 종료·미니맵 배치를 확인했다. 1440×900에서 문장기 선택 후 하단 카드의 병력 5·사기 100 표시를 확인. 국정 표 열기/닫기와 턴 종료 후 2턴·183G 반영을 확인했다. 콘솔 오류 없음. 실제 폰 GPU 성능은 측정하지 않음.
